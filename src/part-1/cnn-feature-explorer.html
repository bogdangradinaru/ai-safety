Camera image→ Convolution→ ReLU→ Feature map→ Max pooling

1. Camera input 16 × 16 grayscale pixels

The blue dashed window shows the filter's current position. Change the scene to inspect a vehicle, pedestrian or lane marking.

2. Convolution filter 3 × 3 shared weights

3. Feature map response of the selected filter

One filter produces one feature map (one channel). A real CNN learns many filters, producing many feature maps.

4. Max-pooling output 2 × 2 regions

Max pooling keeps the strongest activation in each 2 × 2 region, reducing spatial size.

Important: This is a teaching model, not a trained automotive CNN. The small camera scenes and hand-set filters are illustrative. In a real CNN, filter weights are learned from training data, and many layers combine low-level features into more complex patterns. No vehicle, pedestrian or lane classification is produced here.
